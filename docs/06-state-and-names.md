## Names left in code

The repository began as a copy of the jterrazz.com portfolio scaffold, and
Capitaine itself was called Life Captain before. Neither rename was ever
finished:

| Identifier                                      | Where                            |
| ----------------------------------------------- | -------------------------------- |
| `jterrazz-web`, and the portfolio's description | the npm package (`package.json`) |
| "At Life Captain…" as the site description      | `src/app/layout.tsx`             |

The brand's own record of the former names is the glossary in the
`jterrazz-os` corpus, at `home/capitaine/wiki/blueprint/glossary.md`.
